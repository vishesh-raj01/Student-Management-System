# Student Management System

## About the Project

This is a simple Student Management System developed using Python in PyCharm. It helps manage student information easily.

## Features

* Add student details
* View student records
* Manage student information

## Technologies Used

* Python
* PyCharm IDE

## How to Run

1. Download or clone this repository.
2. Open the project in PyCharm.
3. Run `main.py`.
